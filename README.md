# ytakayama.com（一時的な転送用）

`ytakayama.com` に来た古いリンクを `lab.ytakayama.com`（都市システム科学研究室）へ
送るためだけのリポジトリ。**中身を持たない使い捨て**。

- `index.html` `research/` `member/` `access/` … 各パスに対応する転送ページ
- `404.html` … 上記以外のパス（`/member/poster/*.pdf` など）を、同じパスのまま転送する
- `robots.txt` … 転送専用なので検索エンジンには拾わせない

## 役目を終えたら

大学サイト等のリンク差し替えが済んだら、このリポジトリの Settings → Pages から
Custom domain（`ytakayama.com`）を外し、個人サイトのリポジトリに `ytakayama.com` を
設定する。このリポジトリはそのあと削除してよい。
